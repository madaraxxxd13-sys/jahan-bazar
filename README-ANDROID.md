# بسته‌بندی جهان‌بازار به‌عنوان اپ اندروید (برای کافه بازار و مایکت)

⚠️ نکته‌ی مهم: من نمی‌تونم خودم APK بسازم — ساخت APK نیاز به Android Studio (یا حداقل Android SDK) داره که باید روی سیستم خودت اجرا بشه. این راهنما دو مسیر داره؛ مسیر اول خیلی ساده‌تره و Android Studio لازم نداره.

پیش‌نیاز هر دو مسیر: سایتت باید از قبل روی یه آدرس عمومی مثل `https://jahan-bazar.vercel.app` بالا باشه (طبق README اصلی پروژه).

---

## مسیر ۱ (پیشنهادی، بدون نیاز به Android Studio) — PWABuilder

سایت الان یه فایل `manifest.json` و آیکون داره که بهش اضافه کردم، پس آماده‌ی این روشه.

1. برو به [pwabuilder.com](https://www.pwabuilder.com)
2. آدرس سایتت رو وارد کن (مثلاً `https://jahan-bazar.vercel.app`) و روی **Start** بزن.
3. PWABuilder سایتت رو آنالیز می‌کنه و یه امتیاز نشون میده. روی تب **Android** بزن.
4. گزینه‌ی **Generate Package** رو بزن؛ یه فایل APK (یا AAB) امضاشده برات می‌سازه و دانلود می‌کنه. آیکون و اسمی که از `manifest.json` گرفته میشه رو نشون میده — می‌تونی قبلش تغییرشون بدی.
5. فایل APK دانلودشده همونیه که به بازار/مایکت آپلود می‌کنی (مراحل پایین همین فایل).

این روش یه اپ می‌سازه که سایت زنده‌ی خودت رو داخل یه پوسته‌ی اندرویدی (نمایشگر وب) نشون میده — یعنی هر آپدیتی که روی سایت (Vercel) بدی، خودکار توی اپ هم دیده میشه، بدون نیاز به ساخت APK جدید.

---

## مسیر ۲ (پیشرفته‌تر، کنترل بیشتر) — Capacitor + Android Studio

اگه می‌خوای اپ رو بیشتر شخصی‌سازی کنی (مثلاً دکمه‌ی برگشت سخت‌افزاری، اسپلش‌اسکرین اختصاصی):

1. Android Studio رو از [developer.android.com/studio](https://developer.android.com/studio) نصب کن.
2. یه پوشه‌ی جدید بساز و داخلش:
   ```bash
   npm init -y
   npm install @capacitor/core @capacitor/android
   npm install -D @capacitor/cli
   npx cap init "جهان‌بازار" "ir.jahanbazar.app" --web-dir=www
   ```
3. یه پوشه‌ی `www` بساز و داخلش یه `index.html` ساده که کاربر رو مستقیم به سایت زنده‌ات ریدایرکت کنه، یا در فایل `capacitor.config.json`، بخش `server.url` رو مستقیم به آدرس Vercel‌ت ست کن:
   ```json
   {
     "appId": "ir.jahanbazar.app",
     "appName": "جهان‌بازار",
     "webDir": "www",
     "server": {
       "url": "https://jahan-bazar.vercel.app",
       "androidScheme": "https"
     }
   }
   ```
4. اجرا کن:
   ```bash
   npx cap add android
   npx cap sync
   npx cap open android
   ```
5. Android Studio باز میشه. از منوی **Build → Generate Signed Bundle / APK** یه APK امضاشده بساز (یه کلید امضا/keystore جدید می‌سازی و جایی امن نگهش می‌داری — برای هر آپدیت بعدی هم همون کلید لازمه).

## آپلود در کافه بازار

1. برو به [pishkhan.cafebazaar.ir](https://pishkhan.cafebazaar.ir) و به‌عنوان توسعه‌دهنده ثبت‌نام کن (ایمیل و رمز عبور؛ توجه کن ایمیل بعداً قابل تغییر نیست).
2. حساب رو با کد پیامکی تأیید کن و نوع حساب (شخصی/شرکتی) و اطلاعاتت رو تکمیل کن.
3. وارد «پیشخان توسعه‌دهندگان» شو → «برنامه‌ها» → «برنامه‌ی جدید».
4. فایل APK رو آپلود کن؛ کافه بازار خودش اطلاعات پایه (اسم پکیج، نسخه) رو از فایل می‌خونه.
5. اطلاعات نمایشی (اسم، توضیح، آیکون، حداقل چند اسکرین‌شات، دسته‌بندی، اطلاعات تماس پشتیبانی) رو تکمیل کن.
6. درخواست انتشار رو ثبت کن؛ بعد از بررسی تیم بازار، اپ منتشر میشه.

## آپلود در مایکت

1. برو به پنل توسعه‌دهندگان مایکت (`developer.myket.ir`) و حساب توسعه‌دهنده بساز.
2. از منو «برنامه‌ها» → «افزودن برنامه» رو بزن و فایل APK رو آپلود/درگ کن.
3. اسم، توضیح، دسته‌بندی، حداقل ۴ اسکرین‌شات و آیکون رو کامل کن.
4. «ذخیره و ادامه» رو بزن تا برنامه وارد صف بررسی تیم فنی و محتوایی مایکت بشه.
5. وضعیت بررسی از همون پنل قابل پیگیریه؛ در صورت رد شدن، دلیلش رو از طریق ایمیل یا پیام داخلی پنل بهت میگن.

### نکات مهم قبل از ارسال به هر دو استور

- چون اپ محتوای زنده رو از سایت میاره (نه فایل داخل خود APK)، حتماً قبل از ارسال مطمئن شو سایت روی Vercel بالا و در دسترسه.
- اسم پکیج (مثل `ir.jahanbazar.app`) باید یکتا باشه و بین کافه‌بازار/مایکت/به‌روزرسانی‌های بعدی ثابت بمونه.
- برای هر آپدیت بعدیِ ساختار اپ (نه محتوای سایت)، باید نسخه‌ی جدید APK رو با همون کلید امضا بسازی و در پنل هر دو استور بارگذاری کنی.
